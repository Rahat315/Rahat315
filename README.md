## 🚀 Featured Projects

### 🌱 EcoCode Scheduler — Sustainable AI Computing

An AI-assisted, energy-aware task scheduling concept designed to reduce the energy consumption and carbon footprint of AI and analytics workloads.

- LLM-assisted ML pipeline generation
- Energy-aware task scheduling
- GPU workload allocation
- Energy and CO₂ estimation
- OpenAQ environmental data integration

**Technologies:** Java, Spring Boot, Python, React, REST API, LLM Integration.

### 🌾 Smart Agriculture Monitoring System

An IoT-based smart agriculture networking project focused on connecting multiple farms through a centralized monitoring system.

- Multiple farm environments
- IoT sensor integration
- Network communication between farms
- OSPF routing and VLSM subnetting
- Centralized monitoring concept

**Technologies:** Cisco Packet Tracer, IoT, Networking, OSPF.

### 🎓 DIU eduEntry — Admission Candidate Shelter System

A university-focused shelter discovery and management application designed to help admission candidates find accommodation near DIU.

- User registration and authentication
- Shelter management
- Search and filtering functionality
- MySQL database integration

**Technologies:** Java, Spring Boot, MySQL, Thymeleaf.

### ✈️ FlightEase — Airline Reservation System

A C++ airline reservation project developed as a collaborative university project.

- Passenger management
- Flight reservation workflow
- Linked-list based passenger management
- Email validation

**Technologies:** C++.

### 📚 Student Management System

A web-based student management project focused on managing student information and database operations.

**Technologies:** PHP, MySQL.
